# plataforma web para registro de ocorrencias


- o usuário entra na plataforma, e registra algo para a prefeitura/gestão. Essa reclamação vira um ticket, com protocolo que pode ser acompanhado



- tela do usuário
    - email/telefone
    - categoria (dropdown)
    - campo descritivo
    - adicionar imagens
    - coleta de localização


- tela de gestão
    - tela de status
    - resumo com os totais status
    - lista de tickets abertos (estilo Jira)
    - opção de filtros
    - visualizar o ticket e poder enviar resposta
    - anexar foto
